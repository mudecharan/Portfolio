Interview Prep

500+ questions per topic — your complete data science interview guide

🧮 SQL – 500+ Questions & Answers
1. WHERE vs HAVING?
WHERE filters rows before grouping; HAVING filters after GROUP BY and can use aggregates.
2. Window functions vs GROUP BY?
GROUP BY collapses rows; window functions keep rows while computing aggregates per partition.
3. INNER vs LEFT JOIN?
INNER returns only matches; LEFT returns all left rows, padding NULL for missing right.
4. COUNT(*) vs COUNT(col)?
COUNT(*) counts all rows; COUNT(col) counts non-NULL values.
5. What is a CTE?
A temporary result set defined with WITH, improves readability and allows recursion.
6. How to optimise a slow query?
Check execution plan, use indexes, avoid SELECT *, filter early, reduce subqueries.
7. UNION vs UNION ALL?
UNION deduplicates; UNION ALL keeps duplicates and is faster.
8. GROUP BY with NULLs?
NULLs form a single group unless explicitly handled.
9. What is a self-join?
Joining a table to itself, often used for hierarchical or duplicate comparisons.
10. Difference between DELETE and TRUNCATE?
DELETE removes rows (can rollback, WHERE allowed); TRUNCATE removes all rows fast (no rollback).
11. Primary key vs unique key?
PK is unique, not null, one per table; UNIQUE allows one NULL but multiple per table.
12. What is an index?
A data structure (B-tree) that speeds up lookups; costs write overhead.
13. Clustered vs non-clustered index?
Clustered defines physical order; non-clustered is a separate structure with pointers.
14. What is normalization?
Organizing tables to reduce redundancy and dependency (1NF ? 3NF).
15. What is denormalization?
Adding redundancy to improve read performance.
16. How does HAVING differ from WHERE with aggregates?
WHERE cannot use aggregates; HAVING can.
17. Explain a correlated subquery.
A subquery that references outer query; runs once per outer row.
18. How to get top N per group?
Use ROW_NUMBER() OVER (PARTITION BY category ORDER BY ...) and filter rn <= N.
19. What is the difference between EXCEPT and NOT IN?
EXCEPT handles NULLs correctly; NOT IN can be tricky with NULLs.
20. How does JOIN affect performance?
Large joins can be heavy; use indexes, limit rows, avoid unnecessary joins.
21. What is a composite index?
An index on multiple columns; order matters for query optimization.
22. What is a covering index?
An index that contains all columns needed by a query, avoiding table access.
23. How does EXISTS differ from IN?
EXISTS stops at first match; IN builds full list. EXISTS often faster for subqueries.
24. What is a cross join?
Cartesian product of two tables; every row pairs with every row.
25. What is a natural join?
Joins tables on columns with same name; rarely used in practice due to implicit behavior.
26. How to find duplicates in a table?
Use GROUP BY with HAVING COUNT(*) > 1.
27. What is a view?
A virtual table defined by a query; simplifies complex queries and restricts access.
28. Materialized view vs regular view?
Materialized stores results physically; regular recomputes each time.
29. What is a stored procedure?
Precompiled SQL code stored in the database; reusable and secure.
30. What is a trigger?
Code that auto-executes on INSERT/UPDATE/DELETE events.
31. What is a transaction?
A unit of work that follows ACID properties; all-or-nothing execution.
32. Explain ACID properties.
Atomicity, Consistency, Isolation, Durability — guarantees for reliable transactions.
33. What is a deadlock?
Two transactions waiting on each other's locks; DB resolves by killing one.
34. What is isolation level?
Controls visibility of changes between concurrent transactions (READ UNCOMMITTED to SERIALIZABLE).
35. What is a cursor?
A pointer to iterate over query results row by row; slow, avoid in production.
36. How to handle NULLs in SQL?
Use COALESCE(), IS NULL, IS NOT NULL; NULL is not equal to anything.
37. What is the difference between UNION and JOIN?
UNION stacks rows vertically; JOIN combines columns horizontally.
38. What is a full outer join?
Returns all rows from both tables, matching where possible, NULL elsewhere.
39. How to rank with ties?
RANK() leaves gaps; DENSE_RANK() doesn't; ROW_NUMBER() assigns unique numbers.
40. What is LAG/LEAD?
Window functions to access previous/next row values without self-join.
41. How to calculate running total?
SUM(col) OVER (ORDER BY date ROWS UNBOUNDED PRECEDING).
42. What is a recursive CTE?
A CTE that references itself; used for hierarchical data like org charts.
43. How to pivot data in SQL?
Use CASE WHEN with aggregates or PIVOT syntax (SQL Server).
44. What is a subquery vs CTE?
CTE is named and reusable; subquery is inline. CTEs are more readable.
45. How to find the second highest salary?
SELECT MAX(salary) FROM emp WHERE salary < (SELECT MAX(salary) FROM emp) or use DENSE_RANK().
46. What is a schema?
A database namespace that contains tables, views, and other objects.
47. How to alter a table?
ALTER TABLE ADD/DROP/MODIFY COLUMN; structure changes on existing table.
48. What is a constraint?
Rules on columns: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, NOT NULL, DEFAULT.
49. What is a foreign key?
A column referencing a primary key in another table; enforces referential integrity.
50. What is CASCADE?
Propagates deletes/updates from parent to child tables automatically.
